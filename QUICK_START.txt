└────────────────────────────────────────────────────────────────┘

1. Click "Add Seedlings" button
2. Fill in the form (all fields except image, scientific name, 
   survivability, and assigned staff are required)
3. Optionally upload an image
4. Click "Add Seedling"
5. Watch it appear in the table!

┌────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING:                                               │
└────────────────────────────────────────────────────────────────┘

❌ Can't connect to API?
   → Check backend server is running
   → Check .env has VITE_API_URL=http://localhost:8000/api

❌ Images not uploading?
   → Check public/uploads/seedlings/ directory exists
   → Check file size (max 2MB) and type (PNG, JPG, JPEG, GIF)

❌ Form validation errors?
   → Check all required fields are filled
   → Check date format
   → Check enum values match exactly
